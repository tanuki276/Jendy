## B1 · 46 — 変化：ようになる / なくなる / Perubahan kemampuan dan kebiasaan

ようになる は能力や習慣の変化。なくなる は以前あった状態や習慣がなくなることです。

ようになる menyatakan perubahan kemampuan atau kebiasaan; なくなる menyatakan sesuatu tidak lagi terjadi.

### contrast-change-1

**JA → ID:** 「漢字が読めるようになりました」に対応する表現を選んでください。

- Sekarang saya sudah bisa membaca kanji ✓
- Saya tidak bisa membaca kanji lagi
- Saya berniat membaca kanji

読める＋ようになる で以前できなかったことが可能になった変化。

**ID → JA:** Pilih ungkapan Jepang yang sesuai dengan “Sekarang saya sudah bisa membaca kanji”.

- 漢字が読めるようになりました ✓
- 漢字が読めなくなりました
- 漢字を読むつもりです

読めるようになりました menandai kemampuan baru, bukan sekadar niat.

### contrast-change-2

**JA → ID:** 「最近、テレビを見なくなりました」に対応する表現を選んでください。

- Belakangan ini saya mulai terbiasa menonton televisi
- Belakangan ini saya tidak menonton televisi lagi ✓
- Kemarin saya tidak menonton televisi

見なくなる は習慣がなくなったこと。一回見なかったこととは別です。

**ID → JA:** Pilih ungkapan Jepang yang sesuai dengan “Belakangan ini saya tidak menonton televisi lagi”.

- 最近、テレビを見るようになりました
- 最近、テレビを見なくなりました ✓
- 昨日はテレビを見ませんでした

見なくなりました berarti kebiasaan menonton telah berhenti.

### contrast-change-3

**JA → ID:** 「毎日運動するようにしています」に対応する表現を選んでください。

- Saya mulai terbiasa berolahraga setiap hari
- Saya harus berolahraga setiap hari
- Saya berusaha berolahraga setiap hari ✓

ようにしている は意識的な心がけ。ようになる は変化です。

**ID → JA:** Pilih ungkapan Jepang yang sesuai dengan “Saya berusaha berolahraga setiap hari”.

- 毎日運動するようになりました
- 毎日運動しなければなりません
- 毎日運動するようにしています ✓

ようにしています menyatakan usaha yang disengaja, bukan hanya perubahan kebiasaan.

## B1 · 47 — 条件：たら・なら / Syarat dan konteks

ID: contrast-condition

たら は条件や出来事の後、なら は相手の話題や前提を受けた条件に使えます。

たら dapat menyatakan syarat atau setelah kejadian; なら menanggapi asumsi atau topik dari konteks.

### contrast-condition-1

**JA → ID:** 「着いたら連絡してください」に対応する表現を選んでください。

- Tolong hubungi saya sebelum sampai
- Tolong hubungi saya setelah sampai ✓
- Jangan hubungi saya meskipun sudah sampai

着いたら は到着が成立した後の連絡を求めます。

**ID → JA:** Pilih ungkapan Jepang yang sesuai dengan “Tolong hubungi saya setelah sampai”.

- 着く前に連絡してください
- 着いたら連絡してください ✓
- 着いても連絡しないでください

着いたら di sini berarti setelah sampai, bukan sebelumnya.

### contrast-condition-2

**JA → ID:** 「雨だったら、家にいます」に対応する表現を選んでください。

- Meskipun hujan, saya keluar
- Karena hujan, saya di rumah tadi
- Kalau hujan, saya di rumah ✓

たら は仮定の条件。ので の原因とは区別します。

**ID → JA:** Pilih ungkapan Jepang yang sesuai dengan “Kalau hujan, saya di rumah”.

- 雨でも、出かけます
- 雨だったので、家にいました
- 雨だったら、家にいます ✓

だったら menyatakan syarat hipotetis; だったので menyatakan alasan lampau.

### contrast-condition-3

**JA → ID:** 「京都に行くなら、この店がおすすめです」に対応する表現を選んでください。

- Kalau mau ke Kyoto, saya merekomendasikan toko ini ✓
- Setelah pulang dari Kyoto, datanglah ke toko ini
- Karena pergi ke Kyoto, saya menutup toko ini

なら は京都へ行くという相手の計画を前提に助言します。

**ID → JA:** Pilih ungkapan Jepang yang sesuai dengan “Kalau mau ke Kyoto, saya merekomendasikan toko ini”.

- 京都に行くなら、この店がおすすめです ✓
- 京都から帰ったら、この店に来てください
- 京都に行ったので、この店を閉めました

なら menerima rencana ke Kyoto sebagai konteks untuk saran.

## B1 · 48 — 直訳だけでは足りない表現 / Makna di balik terjemahan

ID: contrast-culture

挨拶や配慮の言葉は、字面だけでは機能が分かりません。関係・場面・返事まで学びます。

Sapaan dan perhatian tidak selalu dipahami lewat terjemahan harfiah. Pelajari hubungan, konteks, dan responsnya.

### contrast-culture-1

**JA → ID:** 「もう食べた？」に対応する表現を選んでください。

- Mau makan apa?
- Makan dengan siapa?
- Sudah makan? ✓

文字通りの食事確認に加え、場面によって気遣いとして使います。常に挨拶になるわけではありません。

**ID → JA:** Pilih ungkapan Jepang yang sesuai dengan “Sudah makan?”.

- 何を食べたい？
- 誰と食べた？
- もう食べた？ ✓

もう食べた？ menanyakan makan; Sudah makan? juga dapat menyampaikan perhatian menurut konteks.

### contrast-culture-2

**JA → ID:** 「お先に失礼します」に対応する表現を選んでください。

- Permisi, saya pulang dulu ✓
- Selamat datang kembali
- Selamat jalan

職場などで他の人より先に帰るときの挨拶。直訳は機能を伝えません。

**ID → JA:** Pilih ungkapan Jepang yang sesuai dengan “Permisi, saya pulang dulu”.

- お先に失礼します ✓
- お帰りなさい
- いってらっしゃい

お先に失礼します dipakai ketika pulang lebih dulu dari orang lain, misalnya di kantor.

### contrast-culture-3

**JA → ID:** 「いただきます」に対応する表現を選んでください。

- Ungkapan setelah selesai makan
- Ungkapan sebelum mulai makan ✓
- Ungkapan sebelum tidur

食べ始める前の定型表現。インドネシア語に完全に一致する定型句があるとは限りません。

**ID → JA:** Pilih ungkapan Jepang yang sesuai dengan “Ungkapan sebelum mulai makan”.

- ごちそうさまでした
- いただきます ✓
- おやすみなさい

いただきます adalah ungkapan sebelum makan; terjemahan di sini menjelaskan fungsinya, bukan padanan harfiah.
